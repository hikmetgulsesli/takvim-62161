# Takvim Uygulaması — Ürün Gereksinimleri Dokümanı (PRD)

## 1. Genel Bakış

Takvim-62161, kullanıcıların aylık görünümde tarihleri görüntülemesine, gün eklemesine ve silmesine olanak tanıyan basit, tek sayfalık bir web uygulamasıdır. Uygulama React 18, Vite ve Tailwind CSS ile geliştirilmiş olup tüm veriler tarayıcıda localStorage üzerinde saklanır. Türkçe arayüz ile yerel bir kullanıcı deneyimi sunmayı hedefler. Hedef kitle: bireysel kullanıcılar, günlük planlama ihtiyacı olan herkes.

## 2. Hedefler

- Aylık takvim görünümünde gezinme (önceki/sonraki ay, bugüne dön)
- Herhangi bir güne not/etiket ekleme ve silme
- Tüm verilerin tarayıcıda localStorage ile kalıcı saklanması
- Koyu ve açık tema desteği ile kullanıcı tercihine göre geçiş
- Mobil uyumlu responsive tasarım (320px — 1920px)
- İlk yükleme süresi 2 saniyeden kısa, hızlı ve akıcı UI
- WCAG 2.1 AA erişilebilirlik standartlarına uyum
- Sade, minimal ve temiz bir arayüz tasarımı
- Klavye navigasyonu tam desteği
- Hiçbir harici API veya sunucu bağımlılığı olmadan çalışma

## 3. Tech Stack Detayı

### 3.1 Framework
- **React 18.3.x** — hooks tabanlı bileşen mimarisi, Concurrent Features kullanımı
- **TypeScript 5.x** — tip güvenliği, geliştirici deneyimi

### 3.2 Build Tool
- **Vite 6.x** — hızlı HMR (Hot Module Replacement), modern ESM build

### 3.3 Styling
- **Tailwind CSS 3.4.x** — utility-first CSS, responsive ve dark mode desteği
- Tema: CSS custom properties (Tailwind darkMode: 'class')
- Renk paleti: Slate (gray-toned) taban — neutral ve blue accent

### 3.4 State Management
- **useState / useReducer** — React hooks, context API ile tema yönetimi
- localStorage senkronizasyonu için custom useLocalStorage hook

### 3.5 Storage
- **localStorage API** — tarayıcıda kalıcı veri saklama
- Veri formatı: JSON serialized object
- Key: 'takvim-62161-data'
- TTL: yok (süresiz saklama, kullanıcı temizlemediği sürece)

### 3.6 Routing
- **React Router DOM 7.x** — tek sayfa, ancak URL state desteği için (ileri geri navigasyonu)
- routes: '/' (ana takvim sayfası), '/hakkinda' (opsiyonel bilgi sayfası)

### 3.7 Icons
- **Lucide React** — açık, tutarlı icon seti, SVG tabanlı

## 4. Fonksiyonel Gereksinimler

### 4.1 Aylık Takvim Görünümü
- **Grid yapısı:** 7 sütun (Pazartesi — Pazar), 6 satır (maksimum hafta sayısı)
- **Ay/yıl başlığı:** "Ay Yıl" formatında (ör: "Nisan 2026"), büyük ve okunabilir
- **Navigasyon:** Sol/sağ ok butonları ile önceki/sonraki aya geçiş
- **Bugün vurgusu:** İçinde bulunulan gün farklı bir arka plan rengi ile işaretli
- **Seçili gün:** Kullanıcının tıkladığı gün görsel olarak vurgulanır
- **Boş günler:** Geçerli aya ait olmayan günler soluk/disabled görünümde
- **Gün numaraları:** Her hücrede 1-31 arası gün numarası

**Hata mesajları:**
- "Veri kaydedilemedi tarayıcı depolama alanı dolu" — localStorage full durumunda

**Başarı durumu davranışı:**
- Gün eklendiğinde/silindiğinde anında UI güncellemesi
- localStorage'a otomatik kaydetme

### 4.2 Gün Ekleme
- **Tetikleme:** Takvimdeki herhangi bir güne tıklama
- **Input alanı:** Gün hücresine tıklayınca açılan bir metin giriş kutusu (textarea)
- **Maksimum karakter:** 500 karakter
- **Zorunlu alan:** En az 1 karakter girilmeli (boş bırakılamaz)
- **Timestamp:** Eklenen gün için o anki zaman damgası kaydedilir
- **Düzenleme:** Aynı güne tekrar tıklayarak mevcut not düzenlenebilir

**Hata mesajları:**
- "Lütfen bir not girin" — boş input ile kaydetmeye çalışılırsa
- "Karakter sınırını aştınız (maks 500)" — 500+ karakter girilirse

**Başarı durumu davranışı:**
- Not kaydedildiğinde hücrede küçük bir gösterge (nokta/icon) görünür
- UI anında güncellenir

### 4.3 Gün Silme
- **Tetikleme:** Dolu bir gün hücresinde "sil" butonu (×) görünür, tıklanınca silme işlemi
- **Onay adımı:** "Bu notu silmek istediğinize emin misiniz?" şeklinde onay dialogu
- **İşlem:** Onay sonrası localStorage'dan ilgili kayıt silinir
- **Geri alma:** Yok — silme işlemi kalıcıdır

**Hata mesajları:**
- "Silme işlemi başarısız" — localStorage erişim hatası durumunda

**Başarı durumu davranışı:**
- Hücre içeriği temizlenir, gösterge kaybolur
- UI anında güncellenir

### 4.4 Dark Mode
- **Toggle butonu:** Sağ üst köşede tema değiştirici (ay/güneş ikonu)
- **Depolama:** Tercih localStorage'da 'takvim-62161-theme' key'i ile saklanır
- **Varsayılan:** Sistem tercihine göre (prefers-color-scheme), aksi takdirde açık tema
- **Geçiş animasyonu:** 200ms ease transition
- **Kalıcılık:** Sayfa yenilendiğinde seçili tema korunur

**Başarı durumu davranışı:**
- Tüm sayfa renkleri smooth geçiş ile değişir
- Toggle butonu ikonu da değişir (güneş ↔ ay)

### 4.5 Veri Görüntüleme
- **Gün hücresi içeriği:** Sadece küçük bir gösterge (colored dot veya küçük icon)
- **Detay görünümü:** Hücreye tıklayınca modal şeklinde not içeriği görünür
- **Boş günler:** Herhangi bir gösterge olmadan boş görünür
- **Bugün:** Farklı bir border ve/veya arka plan rengi ile vurgalanmış

## 5. Veri Modeli

### 5.1 Ana Veri Yapısı (localStorage)

```typescript
interface DayEntry {
  date: string;       // "YYYY-MM-DD" formatında tarih
  note: string;       // Kullanıcının girdiği not (max 500 karakter)
  createdAt: number;  // Unix timestamp (ms)
  updatedAt: number;  // Unix timestamp (ms)
}

interface CalendarData {
  entries: Record<string, DayEntry>; // key: "YYYY-MM-DD", value: DayEntry
  version: number;                   // Schema versiyonu
}

interface ThemePreference {
  mode: 'light' | 'dark' | 'system';
}
```

### 5.2 Storage Keys
- `'takvim-62161-data'` — CalendarData JSON string
- `'takvim-62161-theme'` — ThemePreference JSON string

### 5.3 Entity Detayları
**DayEntry:**
- `date`: ISO 8601 date string, primary key olarak kullanılır
- `note`: Kullanıcı metni, trim edilmiş, max 500 karakter
- `createdAt`: entry ilk oluşturulduğunda timestamp
- `updatedAt`: her güncellemede güncellenen timestamp

**CalendarData:**
- `entries`: Record<string, DayEntry>, key = date string
- `version`: number, default 1

## 7. Non-Functional Requirements

### 7.1 Performans
- **İlk yükleme:** < 1.5 saniye
- **LCP:** < 2.0 saniye
- **Bundle size:** < 150KB gzipped
- **Interaction to next paint:** < 100ms
- **localStorage okuma/yazma:** < 50ms
- **CLS:** < 0.1

### 7.2 Erişilebilirlik (WCAG 2.1 AA)
- **Klavye navigasyonu:** Tab, Shift+Tab, Enter, Escape, Arrow keys
- **Screen reader:** ARIA labels, roles, live regions
  - Takvim grid: role="grid", gün hücreleri: role="gridcell"
  - Ay değişikliği: aria-live="polite"
- **Kontrast:** >= 4.5:1 (text), >= 3:1 (large text)
- **Focus state:** Tüm interactive elementlerde visible focus ring
- **Touch hedefleri:** Minimum 44x44px
- **Reduced motion:** prefers-reduced-motion desteği

### 7.3 Tarayıcı Desteği
- **Desktop:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Mobile:** iOS Safari 14+, Android Chrome 90+
- **Responsive:** 320px — 1920px

### 7.4 Güvenlik
- **XSS koruması:** React'ın built-in escaping
- **localStorage veri:** Kullanıcı tarafından değiştirilebilir (client-side risk kabul edilir)

## 11. Kullanıcı Akışı (User Flow)

1. Kullanıcı uygulamayı açar → Ana takvim görünür, içinde bulunulan ay ile
2. Kullanıcı sol/sağ ok ile başka aya gider → Grid güncellenir
3. Kullanıcı herhangi bir güne tıklar → Gün Detay Modal açılır
4. Modal'da not girer ve "Kaydet" basar → localStorage'a kayıt olur, modal kapanır
5. Kullanıcı dolu bir hücreye tekrar tıklar → Mevcut notu düzenleyebilir
6. Kullanıcı silme butonuna basar → Onay Dialog açılır, onaylarsa not silinir
7. Kullanıcı tema toggle basar → Koyu/açık tema arasında geçiş yapar
8. Kullanıcı sayfayı kapatıp geri gelir → Tüm veriler ve tema tercihi korunur
